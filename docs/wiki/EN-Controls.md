# Controls and menus

Morph **0.3.0** · [Index](EN-Index.md) · [Español](ES-Controls.md)

## Default keys

| Key | Action |
|---|---|
| J | Open the form menu |
| R | Primary ability |
| K | Secondary ability |
| Unbound | Return to human |
| Unbound | Open the emote menu |

Change bindings under **Options → Controls → Morph**. Your custom bindings are respected. If a default binding conflicts, Morph tries an available J/K/R key; if none is available it leaves the action unbound. Check controls if J does not open the menu.

## Mob menu

Search forms, inspect details and select a transformation. Dedicated forms use a star and color. The HUD shows the current name and cooldowns for both ability slots.

![Mob menu](images/menu.png)

## Character menu

Choose **Characters** from the mob menu. It includes search, preview, pagination, transformation and return-to-human buttons. The list reflects available resources and server-provided permissions.

![Character menu](images/characters.png)

Open **Emotes** after selecting a character. Choose an available dance and its supported mode. Emotes belong to the current character, so switching characters may change the list.

## Using abilities

Not every form has two active abilities. A binding does not imply the selected form has a power in that slot. The server validates form, state, unlocks and cooldown; repeated key presses do not bypass validation.

The HUD may display a character's name while its abilities come from a linked mob. See [characters and dances](EN-Characters-and-dances.md).
