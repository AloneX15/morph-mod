# Complete Otter tutorial

Morph **0.3.0** · [Index](EN-Index.md) · [Español](ES-Otter-tutorial.md)

## Included resources

Otter is a ready-to-test template. Download the wiki resources or use the automatically created startup directory:

- [character.json](examples/otter/character.json)
- [otter.geo.json](examples/otter/otter.geo.json)
- [otter.animation.json](examples/otter/otter.animation.json)
- [otter.png](examples/otter/otter.png)

Keep them together in `config/morphmod/characters/otter/`. Renaming files requires updating the manifest.

## Test the original template

~~~text
/morph character reload
/morph character select morphmod:otter
/morph emote play demo_dance full
/morph emote stop
/morph emote play demo_dance overlay
~~~

Inspect the model in third person, walk with overlay and check the first-person arm. Equip items, a helmet and elytra to test anchors.

## Create an independent copy

1. Copy all four files to `config/morphmod/characters/explorador/`.
2. Replace `character.json` with [the Explorador manifest](examples/explorador/character.json).
3. The ID becomes `mis_personajes:explorador`, the name becomes Explorador and the Otter rig is retained.
4. Reload and select `mis_personajes:explorador`.
5. Open the copy in Blockbench and modify its texture or geometry while keeping channels and anchors consistent.

The downloadable manifest retains `demo_dance`, a sample emote added by Morph to show both emote modes; the otter's own animation file provides its walk (inside `idle`), swimming, sleeping and item poses, not a dance. To link mechanics, add `"mob": "minecraft:bat"`: this gives bat mechanics to the otter appearance. It does not turn the model into a bat.

## Adaptations

The original geometry has no `waist` bone. Channels targeting it were removed from the bundled copy; the user's original files were not modified. `emote.demo_dance` and its full/overlay registration were added.

The original idle includes procedural movement through MoLang. The template has no separate walk/sprint clips generated by Morph. Binding absent clip names causes validation failure.

This template is a technical starting point, not a grant of rights over third-party characters or resources. Retain the permissions applicable to resources you use.
